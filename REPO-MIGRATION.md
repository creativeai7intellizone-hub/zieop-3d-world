# Zieop Repository Migration

Target repository: `creativeai7intellizone-hub/zieop`

Deployment target: Vercel project for `zieop`

## Final repository rules

- Keep the site self-contained wherever practical.
- Keep bundled 3D model downloads under the Zieop repository.
- Do not present third-party model hosts as the user's download destination.
- Keep model-specific attribution/license information with redistributed assets.
- Keep the GitHub Source Code button pointed at the Zieop repository.

## Important licensing note

The Khronos glTF Sample Assets catalog contains models with different licenses and credits. Do not bulk-copy every upstream model without checking and preserving each model's own redistribution terms. The catalog itself documents model-by-model credits and license details.
